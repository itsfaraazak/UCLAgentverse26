# AgentVerse 2026 — Biotech brief

Source: event text supplied by Vayun on 7 November 2026, previously checked against the event slides. Formatting, punctuation and obvious line-wrap/OCR artefacts have been normalised; requirements have not been expanded. The numbered page references below refer to the original event slide PDF.

## Challenge — Make the path to patients faster

Bringing a new treatment to patients takes over a decade and billions of pounds, and most candidates fail along the way.

Pick a stage of the journey, find a real bottleneck, and build an agent that makes it faster, cheaper or fairer.

### Where to aim

- Research agents
- Multi-agent pipelines
- Clinical support agents
- Your own idea
- Design-build-test-learn agents
- Trial agents

### Build for the people affected

Your users can be researchers, clinicians or patients. Keep a human in the loop for decisions that matter, and show your reasoning so a scientist could check it.

## Technical tools — You don't need a lab

| Area | Listed sources and tools |
| --- | --- |
| Literature | PubMed, Europe PMC, bioRxiv, medRxiv, OpenAlex |
| Drugs and molecules | ChEMBL, PubChem, Open Targets, TDC, MoleculeNet |
| Proteins and structures | UniProt, RCSB PDB, AlphaFold DB |
| Genomics and cells | ClinVar, gnomAD, GEO, GTEx, DepMap, CELLxGENE |
| Clinical trials | ClinicalTrials.gov API, ISRCTN registry |
| Patient data | MIMIC-IV demo, PhysioNet, Synthea |
| Dataset hubs | Kaggle, Hugging Face, Zenodo, Figshare, OpenML |

### Synthetic data is allowed

- Label it and say how you made it.
- Never present it as real-world performance.
- No real patient data, ever.
- Reference every dataset and check its licence.

## Deliverables — Four things to submit

| Deliverable | Requirement |
| --- | --- |
| Working demo | A demo or prototype that runs, even if it is rough. |
| Code | In a public repo, with a short README. |
| One-page write-up | The problem, who it helps, your data, how you evaluated it, and the agent's limits and safeguards. |
| Pitch | Up to 4 minutes, plus 2 minutes for the judges to test your model. |

## Judging — What a top score looks like

| Criterion | Description |
| --- | --- |
| Uniqueness of idea | A fresh approach that goes beyond a literature chatbot or stock model. |
| Real-world need | One specific bottleneck for a named user, with a plausible next step to real use. |
| Science, data and evaluation | Tested against a baseline, with data referenced and licence-checked. |
| Agent design and live demo | A real multi-step agent whose live demo handles a judge's new input. |
| Security and responsible design | Named risks with a mitigation for each, and a human signs off key decisions. |
